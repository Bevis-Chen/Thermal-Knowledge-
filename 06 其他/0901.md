## 1. 靜壓 vs 全壓：Fan PQ 裡的 P 到底是什麼？

在風扇測試標準（AMCA 210 / ISO 5801）中，有幾個關鍵定義： [law.resource](https://law.resource.org/pub/us/cfr/ibr/001/amca.210.1999.pdf)

- **靜壓（Static Pressure, P_s）**：流體在某一點的絕對壓力減去參考大氣壓力，代表流體「推擠」的能力。
- **動壓（Velocity Pressure, P_v）**：與流速相關，P_v = ρ * v²/2，代表流體的動能。
- **全壓（Total Pressure, P_t）**：P_t = P_s + P_v，是靜壓與動壓之和，代表流體在該點的總機械能（忽略位能變化時）。

風扇的「性能」可以用兩種方式表達：

- **Fan Total Pressure Curve**：  
  
  P_t,fan = P_t,outlet - P_t,inlet

- **Fan Static Pressure Curve**（常用於電子散熱、機殼風扇）：  

  P_s,fan = P_s,outlet - P_t,inlet
  
  也就是出口靜壓減去入口全壓。 [cdn.standards.iteh](https://cdn.standards.iteh.ai/samples/56517/033a17e23f764c3bbe224a3380ba9af4/ISO-5801-2017.pdf)

實務上，廠商給的 **Fan PQ Curve** 多數是 **Fan Static Pressure vs Flow**，尤其是機殼風扇、伺服器風扇，因為系統設計者最關心的是「風扇能在機殼進出口之間建立多少靜壓差來克服阻抗」。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

你文中提到：

> 在Fan PQ Curve 圖表裡面描述P是一個代表靜壓的參數...

這在電子散熱領域通常是對的，但要加一個重要註解：**必須確認這條 PQ curve 是 fan static pressure 還是 fan total pressure**，否則跟 system curve 疊圖時會出錯。 [nexoradesign](https://www.nexoradesign.net/post/fan-curve-vs-system-curve-how-to-find-the-real-operating-point-with-example)

## 2. System Impedance Curve 的 P 是什麼？

System Impedance Curve 描述的是：**在特定系統配置下，要維持某個流量 Q，流體從系統入口到出口需要克服的壓力損失ΔP_system**。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

在大多數 turbulent flow 的電子機殼、風道系統中，這個壓力損失近似：

ΔP_system ≈ K * Q²

這裡的 ΔP_system 本質上是：

ΔP_system = P_t,(in,system) - P_t,(out,system)或 P_s,in - P_s,out (視定義)

重點是：**它是「系統需要的壓力」，不是風扇提供的壓力**。 [nexoradesign](https://www.nexoradesign.net/post/fan-curve-vs-system-curve-how-to-find-the-real-operating-point-with-example)

實務上，當我們說「System Curve 的 P」時，通常指的是：

- 若系統進出口都是大空間（自由進自由出）：
  ΔP_system 常用 **static pressure difference** 來表達。
- 若系統是封閉風道：  
  有時會用 **total pressure loss** 來表達。

關鍵仍然是：**要跟 Fan PQ 的 pressure basis 對齊**。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

## 3. 為什麼兩者可以放在同一張圖？能量平衡的觀點

你已經寫得很清楚：

> Fan PQ Curve：在某個流量下，Fan 能提供多少壓力  
> System Impedance Curve：在某個流量下，System 需要克服多少壓力損失  
> Working Point：Fan 提供與 System 需求達到平衡的狀態

從流體力學的角度，可以更嚴格地說：

在穩態、不可壓縮、忽略位能變化的假設下，對「風扇＋系統」這個控制體積寫能量方程式（簡化版 Bernoulli + 風扇做功）：

P_t,outlet - P_t,inlet = ΔP_fan Q - ΔP_loss,system(Q)

在封閉循環或進出口皆為大空間的情況下，穩態時進出口全壓差趨近於 0（或已知邊界條件），因此：

\[ 
\Delta P_{\text{fan}}(Q) = \Delta P_{\text{loss,system}}(Q)
\]

這正是你在文中寫的：

\[
\Delta P_{\text{fan}}(Q_{\text{working-point}}) = \Delta P_{\text{system}}(Q_{\text{working-point}})
\]
\[
Q_{\text{fan}} = Q_{\text{system}} = Q_{\text{working-point}}
\]

**圖形上**：

- Fan PQ Curve 給出：對每個 Q，風扇能提供的 \(\Delta P_{\text{fan}}(Q)\)
- System Curve 給出：對每個 Q，系統需要的 \(\Delta P_{\text{system}}(Q)\)

兩條曲線的交點，就是滿足上述等式的唯一 Q（在單風扇、單系統、單穩態解的情況下），也就是 **operating point / working point**。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

如果：

- 在某個 Q，\(\Delta P_{\text{fan}} > \Delta P_{\text{system}}\)：風扇提供的壓力大於系統阻力，流體會加速，Q 會增加。
- 在某個 Q，\(\Delta P_{\text{fan}} < \Delta P_{\text{system}}\)：風扇提供的壓力不足以克服阻力，流體會減速，Q 會減少。

只有在交點處，壓力供給＝壓力需求，流量不再變化，系統進入穩態。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

## 4. Measurement Plane 為什麼這麼重要？

你對 Measurement Plane 的說明非常到位，我補充幾個跟「疊圖」直接相關的點： [beeindia.gov](https://www.beeindia.gov.in/sites/default/files/4Ch6.pdf)

1. **Pressure definition 依賴測量位置**  
   - Fan static pressure 的定義本身就涉及「入口全壓、出口靜壓」在特定平面的量測。 [law.resource](https://law.resource.org/pub/us/cfr/ibr/001/amca.210.1999.pdf)
   - System pressure loss 也要明確定義「系統入口平面」與「系統出口平面」在哪裡。

2. **若 Fan PQ 與 System Curve 的 reference plane 不一致，就不能直接疊圖**  
   例如：
   - Fan PQ 是在「風扇進出口平面」定義的 \(P_{s,\text{fan}}\)。
   - System Curve 是在「機殼進出口平面」定義的 \(\Delta P_{\text{case}}\)。
   
   若中間還有 duct、filter、heatsink 等元件，且這些元件的壓力損失沒有被正確納入 system curve，那麼兩條曲線其實不是在描述同一個控制體積，疊圖得到的 working point 會偏離真實。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

3. **標準測試（AMCA 210 / ISO 5801）就是在規範這些 plane 與量測方法**  
   - 測量平面要設在流場相對均勻、經過整流的位置。
   - 距離風扇進出口、彎頭、擴散器等要有一定距離，避免局部渦流影響。 [beeindia.gov](https://www.beeindia.gov.in/sites/default/files/4Ch6.pdf)

你在文中提到：

> 必須先確認 Fan PQ 的壓力定義、System Pressure Loss 的定義、Flow Rate 的定義、Measurement Plane，以及 Fan arrangement 與實際系統配置是否相容。

這句話非常關鍵，也是很多實務錯誤的根源。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

## 5. 實務上怎麼「正確疊圖」找 working point？

給你一個精簡的檢查清單，方便日後應用：

1. **確認 Fan PQ 的 pressure basis**  
   - 是 fan static pressure 還是 fan total pressure？ [law.resource](https://law.resource.org/pub/us/cfr/ibr/001/amca.210.1999.pdf)
   - 測試條件（密度、轉速、進出口配置）是否與實際系統接近？

2. **定義系統邊界與 Measurement Plane**  
   - 系統入口平面：例如機殼進風口外側某平面。
   - 系統出口平面：例如機殼出風口外側某平面。
   - 確認 system curve 的 \(\Delta P_{\text{system}}\) 是「從這個入口平面到出口平面」的壓力損失。 [beeindia.gov](https://www.beeindia.gov.in/sites/default/files/4Ch6.pdf)

3. **確認 pressure basis 一致**  
   - 若 Fan PQ 是 fan static pressure，system curve 最好也用 static pressure loss 來表達（同一組進出口 plane）。
   - 若 Fan PQ 是 fan total pressure，system curve 要用 total pressure loss。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

4. **考慮 fan arrangement**  
   - 多風扇串聯：pressure 相加，flow 相同 → 整體 PQ curve 往上疊。
   - 多風扇並聯：flow 相加，pressure 相同 → 整體 PQ curve 往右疊。
   - 疊圖時要用「整個 fan arrangement 的等效 PQ curve」跟 system curve 交會。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

5. **找交點 = working point**  
   - 圖形上：兩條曲線交點。
   - 數值上：解 \(\Delta P_{\text{fan}}(Q) = \Delta P_{\text{system}}(Q)\)。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

- 「Fan PQ 以及 System Impedance 兩條曲線可以放在同一個 pressure-flow chart 做比較」

  → 更精確地說：**在該 Q 下，風扇能提供的壓力正好等於系統需要的壓力損失，因此沒有淨力推動流量變化，系統進入穩態**。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)

- 「Working Point 並不是風扇或系統單獨決定的性能，而是 Fan 與 System 的 Pressure–Flow characteristics 互相匹配後所形成的實際運作狀態」  
  → 這句話非常到位，可以直接當作教材金句。 [amca](https://www.amca.org/educate/articles-and-technical-papers/amca-inmotion-articles/straightening-out-fan-curves.html)
