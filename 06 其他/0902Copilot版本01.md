### 前言
我們已經了解 Fan PQ（風扇壓–流關係）以及 System Impedance（系統阻抗）的意義，本檔案說明如何把這兩個圖表整合，找出風扇在實際系統中的工作點（Working Point），並給出實務上量測與判讀的建議。

### 靜壓 (Static Pressure) 與 全壓 (Total Pressure)
在討論 PQ 曲線時，首先要弄清楚「壓力」指的是哪一種：
- 靜壓 Ps（Static Pressure）：相對於流體平均動能以外的壓力，代表產生壓差以克服系統阻力的能力。
- 動壓 Pd（Dynamic Pressure）：1/2 ρ v^2，與速度有關。
- 全壓 Pt（Total Pressure）：Pt = Ps + Pd。某些風扇曲線或規格提供的是全壓（尤其在open-system 或 ducted system 的情況），有些則提供靜壓。  
在比較 Fan PQ 與 System Impedance 曲線前，必須確定兩者使用的是相同壓力定義（靜壓或全壓），以及相同的 Measurement Plane 與單位。

### PQ 曲線與系統阻抗曲線
- Fan PQ Curve：在固定轉速下，風扇於不同流量 Q 能產生多少壓力 P（通常以 Ps 或 Pt 表示）。常見形式是 P_fan(Q) 隨 Q 下降（或用實測點連成曲線）。
- System Impedance Curve（系統阻抗曲線 / System Curve）：描述在固定系統配置下，為維持不同流量 Q 所需克服的壓力損失 ΔP_system(Q)。典型地，阻力與流量的平方成正比（ΔP ∝ Q^2），但局部阻力或分支會改變曲線形狀。
- Working Point（工作點）：P_fan(Q) 與 ΔP_system(Q) 的交點，表示風扇在系統內的穩定流量與相對壓力。

| 曲線                       | 描述                                    |
|---                        |---                                      |
| Fan PQ Curve              | 在某個流量下，風扇能提供多少壓力（Ps 或 Pt） |
| System Impedance Curve    | 在某個流量下，系統需克服多少壓力損失        |
| Working Point             | Fan 與 System 在相同 Q 下壓力達到平衡的狀態   |

### 測量面 (Measurement Plane) 與邊界條件
要能正確比較兩條曲線，需一致化以下項目：
- 壓力類型：靜壓 Ps 還是全壓 Pt？二者不能混用。
- 測量位置（Measurement Plane）：在系統中明確定義壓力與速度在哪裡量測（例如風扇入口或出口某距離的直管段），使實驗可重現與跨廠商比較。
- 流量單位與標準狀態：使用 m^3/s 或 m^3/h，並註明測試時的空氣密度（或環境溫度、壓力），否則 Pt/Ps 與 Q 的數值會有差異。
- 測試條件：轉速是否固定（有些風扇用 PWM 或電壓控制會改變轉速），是否有回流或分支管路等。

Measurement Plane 的目的：
- 提高量測穩定性與可重現性（通常放在流場較穩定的直段）。
- 作為 Ps / Pt 的基準點。
- 讓不同曲線可在同一基準下比較。

### 工作點
當系統穩定運轉時，風扇提供的壓差與系統的壓力損失相等：
ΔP_fan(Q_working) = ΔP_system(Q_working)  
Q_fan = Q_system = Q_working

也就是 Fan PQ 與 System Curve 的交點即為工作點。重要的是要確認兩曲線中 P 的定義一致（均為 Ps 或均為 Pt），以及用同一測量面和單位。

### 範例：解析交點的簡單數學示範
假設以靜壓 Ps（單位 Pa）與流量 Q（單位 m^3/s）表示，並用簡單二次模型逼近：
- 風扇靜壓（近似）：P_fan(Q) = P0 - k_f Q^2
- 系統壓力損失（近似）：ΔP_system(Q) = k_s Q^2

工作點滿足：
P0 - k_f Q^2 = k_s Q^2  
→ P0 = (k_f + k_s) Q^2  
→ Q_working = sqrt( P0 / (k_f + k_s) )

範例數值（僅示範）：
- P0 = 250 Pa（無流時的靜壓）
- k_f = 400 (Pa·s^2/m^6)（風扇模型係數）
- k_s = 200 (Pa·s^2/m^6)（系統阻抗係數）

則 Q_working = sqrt(250 / (400 + 200)) = sqrt(250 / 600) ≈ 0.646 m^3/s  
（換算約 2326 m^3/h）

注意：以上係簡化模型。實務中曲線不是精確二次函數，需以實測數據擬合或直接繪圖找交點。且單位與密度需保持一致。

### 實務建議與注意事項
- 確認壓力定義：同時使用 Ps 或 Pt；若資料來源混用，必須先換算或重新量測。
- 標註測試條件：轉速、溫度、氣壓、測量面位置、流量單位、是否有分流/回路等。
- 測量裝置：使用靜壓孔靶、皮托管（測動壓）、熱式流量計或節流裝置時，注意儀器誤差與校正。
- 風扇定律（Fan Laws）：在不同轉速下，Q ∝ N，P ∝ N^2，功率 ∝ N^3（近似），可用於不同轉速間的曲線換算（在相似條件下）。
- 系統變動：系統更改（加濾網、線路改動、散熱器堵塞）會改變系統曲線與工作點。
- 多風扇情形：風扇並聯/串聯會改變等效系統曲線與單機工作點，需用等效曲線或逐步模擬/測量。
- 安全邊際：在設計時，考慮風扇老化、灰塵堆積、環境變化帶來的流量/壓力衰減。
